# Himalayan Spirit Adventures (React + Supabase)
1. `npm install`
2. `npm run dev` then open http://localhost:5173
Admin: http://localhost:5173/admin/login
The .env holds only the public (publishable) Supabase key. Never put a service-role key in this project.

## Sync to GitHub
Run `./sync.sh` (Git Bash on Windows). It shows the changes, asks for confirmation, and never force-pushes.
